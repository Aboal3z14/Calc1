1Intuitive definition & graph

Definition in words

The limit is the number f(x) gets close to when x gets close to a. We write limx→a f(x) = L.

Check from the left and from the right. If both give the same number, that is the limit.

f(x) = (x² − 1)/(x − 1) = x + 1  for x ≠ 1

f(x)

Left and right limits are both 2, so the limit exists even though f(1) is undefined.

2Applications

Definition in words

A limit is the value something heads toward when a process keeps going or keeps shrinking.

  • Instantaneous speed: average speed over a shrinking time interval.
  • Derivatives: lim h→0 (f(x+h) − f(x))/h.
  • Integrals: limits of Riemann sums.
  • Compound interest: (1 + 1/n)ⁿ → e.
  • Big-O analysis: compare growth as n → ∞.
  • Numerical methods: iterations converge to a root.
  • Machine learning: gradient descent converges to a minimum.
  • Graphics & physics: numerical derivatives give smooth motion.

4Precise definition optional

Definition in words

L is the limit if you can get f(x) as close to L as you want (within ε) by keeping x close enough to a (within δ).

∀ε > 0 ∃δ > 0 : 0 < |x − a| < δ ⟹ |f(x) − L| < ε

Example: f(x) = 2x + 1, a = 3, L = 7. Since |f(x) − 7| = 2|x − 3|, choosing δ = ε/2 always works.

Amber band: allowed outputs. Blue band: inputs within δ. Every x in the blue band lands in the amber band, however small ε gets.
